# 🐦 Twimba


Twimba is a simple Twitter-like interactive feed built using Vanilla JavaScript.  
It was created as part of my learning journey with Scrimba, where I learned how to build interactive user interfaces from scratch using HTML, CSS, and JavaScript.

## 🎯 Design Requirements 👍
The Twimba project aims to simulate a simple social media feed with interactive features.  
The design requirements include:
- Displaying tweets dynamically from data  
- Allowing users to create new tweets  
- Enabling like and retweet interactions  
- Showing and hiding replies for each tweet  

---

## 🛠️ Technologies Used 👌
The Twimba project was built using the following technologies:
- HTML5  
- CSS3  
- JavaScript (ES6+)  
- Font Awesome (icons)  
- Google Fonts  
- UUID library (for unique IDs)

---

## ✨ Features 😎
The Twimba project includes the following features:
- Create and post new tweets dynamically  
- Like and unlike tweets  
- Retweet functionality  
- Toggle replies section  
- Display nested replies  
- Fully dynamic UI rendering

## 📥 Installation ✔
To use the Twimba project, follow these steps:

1. Clone the repository:
   ```bash
   [git clone https://github.com/your-username/twimba.git](https://github.com/YaraElBassaal/twimba.git)
2. Open the project folder.
3. Open the `index.html` file in your web browser.

## Usage💻
Once the Twimba project is running in your browser, you can:
- Write a tweet in the input box
- Click the “Tweet” button to post it
- Like or retweet posts
- Click the comment icon to view replies
